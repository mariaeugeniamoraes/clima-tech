# 🌦️ Clima Tech

<p align="center">
  Aplicação web para consulta de informações climáticas em tempo real.
</p>

---

## 📖 Sobre o projeto

O **Clima Tech** é uma aplicação web desenvolvida para consultar informações sobre o clima de diferentes localidades de forma simples e interativa.

A aplicação utiliza dados em tempo real da **API OpenWeatherMap**, permitindo visualizar informações climáticas atualizadas através de uma interface moderna e intuitiva.

O projeto foi desenvolvido utilizando **HTML, CSS e JavaScript**, integrando uma API externa para obtenção dos dados meteorológicos.

---

## ✨ Funcionalidades

- 🔍 Pesquisa de clima por localização
- 🌡️ Exibição da temperatura
- 🌦️ Informações sobre as condições climáticas
- 🔄 Consulta de dados em tempo real
- 🌐 Integração com API externa
- 🎨 Interface interativa
- ✨ Animações e elementos visuais

---

## 🚀 Tecnologias utilizadas

<p>
  <img src="https://skillicons.dev/icons?i=html,css,js" />
</p>

- **HTML5** — estrutura da aplicação
- **CSS3** — estilização, layout e animações
- **JavaScript** — lógica e manipulação dos dados
- **OpenWeatherMap API** — fornecimento dos dados climáticos

---

## 🔌 Integração com API

A aplicação realiza requisições à **OpenWeatherMap API** para obter informações meteorológicas atualizadas.

Os dados recebidos são processados pelo JavaScript e apresentados dinamicamente na interface da aplicação.
